# 📊 Madhav E-commerce Sales Dashboard – Power BI

## 📌 Project Overview

Madhav E-commerce Sales Dashboard is an interactive data visualization and business intelligence project developed using Microsoft Power BI.

The dashboard analyzes e-commerce sales data and provides insights into sales amount, profit, quantity sold, average order value, customer performance, state-wise sales, category-wise quantity, payment modes, monthly profit trends, and sub-category profitability.

---

## 🎯 Project Objective

The main objective of this project is to analyze e-commerce sales data and build an interactive dashboard that helps understand:

- Overall sales performance
- Profitability
- Quantity sold
- Average Order Value (AOV)
- State-wise sales
- Category-wise sales quantity
- Customer-wise sales
- Payment mode distribution
- Monthly profit trends
- Sub-category profitability

## 📂 Dataset

The project uses two datasets:

### Orders Dataset

Contains information related to orders and customers.

| Column | Description |
|---|---|
| Order ID | Unique identifier of an order |
| Order Date | Date on which the order was placed |
| CustomerName | Name of the customer |
| State | Customer's state |
| City | Customer's city |

### Details Dataset

Contains sales and transaction information.

| Column | Description |
|---|---|
| Order ID | Unique identifier of an order |
| Amount | Sales amount |
| Profit | Profit generated from the order |
| Quantity | Quantity of products sold |
| Category | Product category |
| Sub-Category | Product sub-category |
| PaymentMode | Payment method used |

## 📈 Dashboard Analysis

### 1. Sales by State

The dashboard analyzes sales amount across different states, including:

- Maharashtra
- Madhya Pradesh
- Uttar Pradesh
- Delhi

This helps identify geographical sales performance.

### 2. Quantity by Category

Product quantity is analyzed across major categories:

- Clothing
- Electronics
- Furniture

The dashboard provides a percentage-based distribution of quantity sold.

### 3. Profit by Month

Monthly profit is visualized to identify:

- Profitable months
- Loss-making months
- Monthly performance trends

### 4. Sales by Customer

The dashboard compares sales generated by different customers and helps identify high-value customers.

### 5. Quantity by Payment Mode

The dashboard analyzes product quantity according to payment methods such as:

- COD
- UPI
- Debit Card
- Credit Card
- EMI

### 6. Profit by Sub-Category

Profit is analyzed across product sub-categories such as:

- Printers
- Bookcases
- Saree
- Accessories
- Tables
